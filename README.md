# 🚴 NYC Citi Bike Visualization

## 📖 Description

Final dashboard link: https://rprithvii.github.io/Spin-City/

This project provides **interactive visualizations of NYC Citi Bike data** using Python.  
It explores usage patterns, trip statistics, and popular stations to help understand how New Yorkers use Citi Bikes.

The project is built using **Python**, **pandas**, and **data visualization libraries** like **Matplotlib**, **Seaborn**, or **Plotly**.

---

## ✨ Features
- Analyze trip counts, durations, and bike usage trends  
- Visualize **popular start and end stations**  
- Explore temporal patterns: by hour, day, or month  
- Compare **user types** (Subscriber vs Customer)  
- Easy-to-run Python scripts and Jupyter notebooks for analysis
